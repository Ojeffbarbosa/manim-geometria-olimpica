# manim-geometria-olimpica
Repositório com animações em MP4 e códigos em Python produzidos no contexto de um artigo de Matemática sobre o Teorema de Viviani, o Ponto de Fermat e o Teorema de Napoleão, incluindo aplicações em problemas olímpicos e exercícios resolvidos por meio de animações desenvolvidas com o Manim.
